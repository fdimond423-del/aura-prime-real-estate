## 💻 Technical Architecture & Design Intelligence

- **Design System**: *Exaggerated Minimalism* (Cinzel Display + Plus Jakarta Sans body typography)
- **Aesthetic**: Deep Obsidian (`#050608`), Cyber Lime accents (`#98f014`), Champagne Gold highlights (`#d4af37`), hairline glassmorphism (`backdrop-filter: blur(20px)`).
- **Core Interactive Engines**:
  - **Live Multi-Currency Engine**: Instant conversion across USD ($), EUR (€), AED (د.إ), and GBP (£).
  - **Hero Filter Bar (21st.dev Pattern)**: Multi-criteria filtering by Acquisition type (Buy, Rent, Yield, Islands), territory, and valuation tier.
  - **Capital Yield & Financing Simulator**: Real-time loan servicing, rental yield cash carry, and 10-year compounded equity projection.
  - **Property Dossier Modal**: Interactive photo gallery thumbnail switcher, structural specifications, and direct private viewing scheduler.
  - **Continuous 60 FPS Ticker Rail**: Real-time luxury index feeds.
